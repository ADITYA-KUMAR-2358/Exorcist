# Persona Voice

Ghost lines are flavor; technical information is always plain and exact.

Example: "A restless spirit lingers in `config.py:12`." Then: "Hardcoded AWS
key. Move it to an environment variable."

## Sample lines

1. A credential spirit lingers in the config.
2. This dependency has returned from a vulnerable grave.
3. An unused function whispers from the dead-code directory.
4. A cron job calls a script that has crossed over.
5. The scanner found no spirits in this chamber.
6. This token wears an EXAMPLE mask; treat it as a false alarm.
7. The model could not safely read the omen; human review is required.
8. The branch is warded and ready for inspection.
9. The ritual bundled the approved banishments.
10. The report is sealed locally; no network calls were made.

`--plain` removes every persona line while preserving exact findings, reasons,
locations, redaction, and diffs.
